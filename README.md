# ClickerAvengers

**ClickerAvengers** is a browser-based idle clicker game inspired by [*ClickerHeroes*](https://store.steampowered.com/app/363970/Clicker_Heroes/) and developed using **JavaScript**, **HTML5**, and **CSS3**.

The project was created from scratch without using game engines or external frameworks. The goal was to explore modern web development concepts while implementing core game mechanics, animations, sound effects, and interactive UI elements.

## Features

* 🖱️ Click-based combat system with animated enemies.
* 👾 Multiple monsters with unique health, rewards, and boss encounters.
* 📈 Progressive difficulty scaling as the player advances through levels.
* 💰 Coin reward system for defeating enemies.
* 🎵 Background music and sound effects with persistent settings.
* 🌗 Day/Night theme switching.
* 🌍 Multi-language support.
* 💾 Automatic saving of game settings using Local Storage.
* ✨ Visual click effects and smooth UI animations.
* 📱 Responsive interface that adapts to different screen sizes.

## Technologies

* JavaScript (ES6 Modules)
* HTML5 Canvas
* CSS3
* Local Storage API

## Purpose

This project was built to improve my frontend development skills by working with object-oriented JavaScript, modular architecture, DOM manipulation, Canvas rendering, game logic, and browser APIs. It was also made to make my 27 active users happy!
